Acoplamento e Coesão

Acoplamento

É o grau de dependência entre componentes. Alto acoplamento: componentes dependem muito uns dos outros. Baixo acoplamento: componentes possuem menos dependências diretas.
Exemplo de alto acoplamento:
A → B → C → D → E
Uma alteração em A pode afetar toda a cadeia. Uma forma de reduzir o acoplamento é fazer componentes dependerem de abstrações/interfaces, em vez de implementações específicas.

Coesão

É o quanto as responsabilidades de um componente estão relacionadas entre si. Exemplo de alta coesão:

  • UsuarioService
  • Criar usuário
  • Atualizar usuário
  • Buscar usuário
  • Excluir usuário

Todas as funções estão relacionadas a usuários.
Exemplo de baixa coesão:
Um único módulo responsável por:
  • Login
  • Gerar PDF
  • Calcular frete
  • Processar pagamento
  • Enviar e-mail

Regra importante

Alta coesão + baixo acoplamento = arquitetura mais fácil de manter e evoluir.
