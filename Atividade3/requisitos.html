Requisitos e Atributos de Qualidade

Requisitos funcionais

Dizem o que o sistema deve fazer.

    Exemplos:
  • Cadastrar usuários;
  • Fazer login;
  • Cadastrar produtos;
  • Criar pedidos;
  • Realizar pagamentos;
  • Gerar relatórios.
Exemplo: "O sistema deve permitir que o usuário faça login utilizando e-mail e senha."

Requisitos não funcionais

Dizem como o sistema deve funcionar ou quais condições ele deve atender.

    Exemplos:
  • Desempenho;
  • Segurança;
  • Disponibilidade;
  • Escalabilidade;
  • Confiabilidade;
  • Manutenibilidade;
  • Observabilidade;
  • Testabilidade.
Exemplo: "O sistema deve responder às requisições em até 500 ms." Os requisitos não funcionais são muito importantes para a arquitetura porque podem determinar quais tecnologias e estruturas serão utilizadas.

Principais atributos de qualidade Desempenho: eficiência do sistema.

  • Latência: tempo para uma operação ser concluída.
  • Throughput: quantidade de operações processadas em determinado período.
  • Escalabilidade: capacidade de lidar com aumento de demanda.
  • Vertical: aumentar recursos de uma máquina.
  • Horizontal: adicionar novas máquinas/instâncias.
  • Disponibilidade: capacidade de permanecer funcionando e acessível.

Pode utilizar:
  • Redundância;
  • Replicação;
  • Balanceamento de carga;
  • Failover;
    • Backup;
  • Recuperação de desastres.

Confiabilidade: capacidade de funcionar corretamente durante determinado período. Manutenibilidade: facilidade para corrigir, modificar e evoluir o sistema. A ISO/IEC 25010:2023 apresenta um modelo relacionado à qualidade de produtos e sistemas de software.
