Fundamentos

Arquitetura de Software é a forma como um sistema é estruturado e organizado. Ela define os principais componentes, suas responsabilidades, relacionamentos, dependências, tecnologias e restrições.
O processo pode ser resumido em: Requisitos → Arquitetura → Design → Implementação → Testes → Implantação → Manutenção

  • Arquitetura × Design × Implementação
  • Arquitetura: decisões estruturais de maior impacto.
  • Monólito ou microsserviços?
  • Banco relacional ou não relacional?
  • Comunicação síncrona ou assíncrona?
  • Cloud ou infraestrutura local?
  • Design: organização interna dos componentes.

  • Implementação: transformação dessas decisões em código.

Conceitos fundamentais

Componentes: partes do sistema responsáveis por determinadas funcionalidades. Dependências: quando um componente precisa de outro para realizar uma tarefa. Modularidade: divisão do sistema em partes relativamente independentes, facilitando manutenção, testes e evolução. Abstração: esconder detalhes desnecessários e mostrar apenas o que é relevante. Encapsulamento: proteger os detalhes internos de um componente, evitando dependência direta de sua implementação.
