# 📦 Big Data

**Big Data** está relacionado ao tratamento de conjuntos de dados que apresentam características que tornam seu processamento mais complexo do que abordagens tradicionais.

---

## 📡 Fontes de dados

Os dados podem ser produzidos por:

* Internet;
* Smartphones;
* Redes sociais;
* Sensores;
* GPS;
* IoT;
* Aplicativos;
* Sistemas corporativos;
* Transações financeiras.

---

## 🎯 Desafio

O desafio não está apenas em armazenar grandes quantidades de dados.

É necessário conseguir:

* Armazenar;
* Processar;
* Analisar;
* Interpretar;
* Gerar valor.
