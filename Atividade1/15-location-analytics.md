# 🌎 Location Analytics

**Location Analytics** combina dados geográficos com técnicas de análise.

---

## 📍 Dados utilizados

Pode utilizar:

* GPS;
* Mapas;
* Dados demográficos;
* Localização de clientes;
* Dados urbanos.

---

## 💡 Aplicações

Location Analytics pode ser utilizado em:

* Logística;
* Transporte;
* Planejamento urbano;
* Saúde;
* Marketing;
* Segurança;
* Escolha de localização de lojas.

---

## 🔄 Exemplo

Uma empresa pode combinar:

```text
Localização dos clientes
        +
Dados demográficos
        +
Mapa
        +
Histórico de compras
        ↓
Análise geográfica
        ↓
Decisão
```

Isso pode ajudar a identificar regiões com maior demanda ou locais estratégicos para novos estabelecimentos.
