# 👩‍💻 Profissões Relacionadas

A área de dados possui diferentes profissionais, cada um com responsabilidades específicas.

---

# 📊 Data Analyst

Trabalha principalmente com:

* SQL;
* Relatórios;
* Dashboards;
* Indicadores;
* Análise exploratória;
* Visualização.

Seu trabalho está frequentemente relacionado à interpretação de dados existentes para responder perguntas de negócio.

---

# 🔬 Data Scientist

Trabalha principalmente com:

* Estatística;
* Programação;
* Machine Learning;
* Modelagem;
* Análise preditiva.

Pode desenvolver modelos para identificar padrões e realizar previsões.

---

# 🏗️ Data Engineer

Responsável por construir e manter:

* Pipelines de dados;
* Sistemas de dados;
* Processos ETL/ELT;
* Infraestrutura de dados.

Seu trabalho fornece a infraestrutura necessária para que outros profissionais possam utilizar os dados.

---

# 🏢 Chief Data Officer — CDO

Atua estrategicamente na gestão, governança e utilização dos dados dentro da organização.

---

## 📌 Comparação

| Profissão      | Foco principal               |
| -------------- | ---------------------------- |
| Data Analyst   | Análise e visualização       |
| Data Scientist | Modelagem e Machine Learning |
| Data Engineer  | Infraestrutura e pipelines   |
| CDO            | Estratégia e governança      |
