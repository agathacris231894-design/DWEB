# 📊 Variáveis

Uma **variável** representa uma característica que pode assumir diferentes valores.

Exemplo:

```text
Aluno
├── Nome
├── Idade
├── Curso
├── Nota
└── Estado civil
```

---

# 🏷️ Variáveis Categóricas

Representam categorias ou grupos.

Exemplo:

```text
Estado civil:

- Casado
- Solteiro
- Divorciado
```

## Variáveis Nominais

Não possuem uma ordem natural.

Exemplo:

```text
Cor:

- Azul
- Vermelho
- Verde
```

Não existe uma ordem natural entre essas categorias.

---

## Variáveis Ordinais

Possuem uma ordem.

Exemplo:

```text
Avaliação:

- Ruim
- Regular
- Bom
- Excelente
```

Existe uma progressão entre as categorias.

---

# 🔢 Variáveis Quantitativas

Representam valores numéricos.

## Variáveis Discretas

Normalmente representam contagens.

Exemplo:

```text
Número de filhos:

0
1
2
3
```

Os valores são normalmente contáveis e separados.

---

## Variáveis Contínuas

Podem assumir diferentes valores dentro de determinado intervalo.

Exemplo:

```text
Altura:

1.65
1.72
1.803
```

---
