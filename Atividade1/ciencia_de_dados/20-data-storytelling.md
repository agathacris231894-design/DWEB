# 📖 Data Storytelling

**Data Storytelling** combina dados, contexto, visualização e narrativa para comunicar resultados de análises.

---

## 🧩 Elementos

```text
DADOS
  +
CONTEXTO
  +
VISUALIZAÇÃO
  +
NARRATIVA
  ↓
COMUNICAÇÃO
```

---

## 🎯 Objetivo

O objetivo é tornar os resultados mais compreensíveis para diferentes públicos e apoiar a tomada de decisões.

---

## 💡 Exemplo

Em vez de apresentar somente:

```text
Vendas ↓ 15%
```

podemos apresentar:

```text
As vendas diminuíram 15% no último trimestre.

A maior redução ocorreu entre novos clientes.

Os dados indicam uma queda nas conversões.

Possível ação:
aumentar as estratégias de aquisição e retenção.
```

A narrativa fornece **contexto e significado** aos números.
