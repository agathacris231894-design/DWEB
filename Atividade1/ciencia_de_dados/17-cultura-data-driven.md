# 🌱 Cultura Orientada por Dados

Uma organização não precisa apenas de tecnologia para se tornar Data-Driven.

Também é necessário desenvolver uma cultura que incentive:

* Uso de dados;
* Compartilhamento de informações;
* Capacitação;
* Tomada de decisões baseada em evidências;
* Uso de indicadores;
* Experimentação.

---

## 🧩 Elementos necessários

```text
TECNOLOGIA
    +
PESSOAS
    +
PROCESSOS
    +
CULTURA
    ↓
ORGANIZAÇÃO DATA-DRIVEN
```

---

## 🎯 Objetivo

O objetivo é fazer com que diferentes áreas da organização consigam utilizar dados para:

* Compreender problemas;
* Avaliar resultados;
* Tomar decisões;
* Identificar oportunidades;
* Melhorar processos.
