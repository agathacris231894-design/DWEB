# 🤖 Machine Learning

**Machine Learning (Aprendizado de Máquina)** é uma área da Inteligência Artificial que utiliza algoritmos capazes de aprender padrões a partir de dados.

---

## 🔄 Fluxo simplificado

```text
DADOS HISTÓRICOS
       ↓
    ALGORITMO
       ↓
      MODELO
       ↓
   NOVOS DADOS
       ↓
    PREVISÃO
```

---

## 💡 Aplicações

Machine Learning pode ser utilizado em:

* Sistemas de recomendação;
* Detecção de fraude;
* Classificação;
* Previsão de preços;
* Reconhecimento de padrões.

---

## 🧠 Conceito

Em vez de programar manualmente todas as regras para uma tarefa, algoritmos de Machine Learning podem identificar padrões presentes nos dados e utilizá-los para realizar previsões ou classificações.

---

## 📌 Relação

```text
Inteligência Artificial
          ↓
   Machine Learning
          ↓
    Deep Learning
```

Deep Learning é uma abordagem de Machine Learning baseada em redes neurais artificiais com múltiplas camadas.
