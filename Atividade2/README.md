# 🌐 Desenvolvimento Web

Repositório destinado às **atividades, exercícios, projetos e conteúdos desenvolvidos na disciplina de Desenvolvimento Web da FATEC Sorocaba**.

## 📚 Sobre a disciplina

Este diretório reúne materiais produzidos ao longo da disciplina, contemplando conceitos e práticas relacionados ao desenvolvimento de aplicações para a Web.

Os conteúdos têm como objetivo registrar o processo de aprendizagem e servir como material de consulta para estudantes interessados em desenvolvimento web.

## 📂 Conteúdos

Os materiais deste diretório podem incluir:

* 🌐 Estrutura e fundamentos da Web
* 📝 HTML
* 🎨 CSS
* ⚙️ JavaScript
* 📱 Desenvolvimento de páginas responsivas
* 🔗 Integração entre tecnologias Web
* 💻 Exercícios e atividades práticas
* 🚀 Projetos desenvolvidos durante a disciplina
* 📖 Anotações e materiais de estudo

## 🎯 Objetivo

Organizar e documentar as atividades realizadas durante a disciplina, facilitando o acompanhamento da evolução dos conhecimentos em **Desenvolvimento Web** e disponibilizando os materiais para consulta e estudo.

## 🏫 Instituição

**FATEC Sorocaba — Faculdade de Tecnologia de Sorocaba**

**Curso:** Análise e Desenvolvimento de Sistemas
**Disciplina:** Desenvolvimento Web
