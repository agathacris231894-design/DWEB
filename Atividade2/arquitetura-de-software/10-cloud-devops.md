# ☁️ 10 — Cloud, Cloud Native e DevOps

## Cloud Computing

Cloud Computing fornece recursos computacionais através da internet.

Exemplos:

* máquinas virtuais;
* bancos de dados;
* armazenamento;
* redes;
* funções;
* serviços gerenciados.

---

# Cloud Native

Cloud Native envolve práticas voltadas para construção e operação de sistemas modernos em ambientes cloud.

Características:

* containers;
* automação;
* microsserviços;
* escalabilidade;
* observabilidade;
* DevOps.

---

# Containers

```text
Aplicação
   ↓
Docker
   ↓
Container
```

Containers fornecem isolamento e empacotamento consistente.

---

# Kubernetes

```text
Internet
   ↓
Load Balancer
   ↓
Kubernetes
   ├── Pod
   ├── Pod
   └── Pod
```

Pode realizar:

* scheduling;
* scaling;
* service discovery;
* self-healing;
* rolling deployment.

# CI/CD

### CI — Continuous Integration

Integração contínua do código.

### CD — Continuous Delivery / Deployment

Automação da entrega ou implantação.

# Infraestrutura como código

```text
Código
  ↓
Terraform
  ↓
Infraestrutura
```

Isso permite:

* versionamento;
* repetibilidade;
* automação;
* padronização.

---

# Well-Architected

Frameworks como o AWS Well-Architected utilizam pilares para avaliar arquiteturas.

Entre eles:

* excelência operacional;
* segurança;
* confiabilidade;
* eficiência de desempenho;
* otimização de custos;
* sustentabilidade.

---

# 📌 Ideia principal

Cloud Native não significa simplesmente "colocar uma aplicação na nuvem".

É uma abordagem arquitetural e operacional.
