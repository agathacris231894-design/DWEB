# ✅ 16 — Checklist de Arquitetura

## Requisitos

* [ ] O problema está claramente definido?
* [ ] Os usuários foram identificados?
* [ ] Os requisitos funcionais foram levantados?
* [ ] Os requisitos não funcionais foram levantados?

---

## Arquitetura

* [ ] Os componentes possuem responsabilidades claras?
* [ ] O sistema possui alta coesão?
* [ ] O acoplamento está controlado?
* [ ] As dependências estão organizadas?

---

## Qualidade

* [ ] O sistema possui desempenho adequado?
* [ ] É escalável?
* [ ] É seguro?
* [ ] É confiável?
* [ ] É testável?
* [ ] É observável?
* [ ] É manutenível?

---

## Operação

* [ ] Existe CI/CD?
* [ ] Existe monitoramento?
* [ ] Existem logs?
* [ ] Existem métricas?
* [ ] Existem traces?
* [ ] Existem backups?
* [ ] Existe estratégia de recuperação?

---

## Segurança

* [ ] Autenticação implementada?
* [ ] Autorização implementada?
* [ ] Segredos protegidos?
* [ ] Criptografia utilizada?
* [ ] Princípio do menor privilégio?
* [ ] Controle de acesso?

---

## Documentação

* [ ] README?
* [ ] Diagramas?
* [ ] ADRs?
* [ ] Decisões arquiteturais registradas?
* [ ] Instruções de execução?

---

## Evolução

* [ ] A arquitetura pode evoluir?
* [ ] Existem pontos de acoplamento excessivo?
* [ ] Existe dívida técnica?
* [ ] As principais decisões possuem justificativa?

---

# 🧠 Perguntas fundamentais

Antes de escolher uma arquitetura, pergunte:

1. **Qual problema estou resolvendo?**
2. **Quais são os requisitos?**
3. **Quais são as restrições?**
4. **Quais atributos de qualidade são prioritários?**
5. **Quais alternativas existem?**
6. **Quais são os trade-offs?**
7. **Como essa arquitetura poderá evoluir?**

> **Arquitetura é decisão, não decoração.**
