# 🎯 17 — Conclusão

Arquitetura de Software é uma área fundamental da Engenharia de Software porque influencia diretamente a maneira como sistemas são construídos, executados, mantidos e evoluídos.

Durante o estudo foram abordados:

* fundamentos;
* requisitos;
* atributos de qualidade;
* estilos arquiteturais;
* padrões;
* Design Patterns;
* SOLID;
* microsserviços;
* Event-Driven Architecture;
* Serverless;
* Cloud Native;
* DevOps;
* segurança;
* observabilidade;
* documentação;
* ferramentas;
* Inteligência Artificial;
* tendências atuais.

---

## 🧠 Principal aprendizado

Não existe uma arquitetura universalmente melhor.

Uma arquitetura deve ser escolhida de acordo com:

```text
Problema
   +
Requisitos
   +
Restrições
   +
Qualidade
   +
Custos
   +
Equipe
   +
Evolução
```

---

## 🚫 Evitar arquitetura por moda

Não é necessário utilizar:

```text
Kubernetes
+
Microsserviços
+
Kafka
+
Service Mesh
+
Multi-cloud
```

em todo projeto.

A complexidade deve existir porque existe uma necessidade.

---

## 🚀 Arquitetura moderna

As principais tendências atuais envolvem:

* Cloud Native;
* containers;
* Kubernetes;
* Serverless;
* Event-Driven;
* Platform Engineering;
* observabilidade;
* sustentabilidade;
* Inteligência Artificial.

---

## 🤖 IA

A Inteligência Artificial está modificando tanto a maneira como arquiteturas são projetadas quanto os próprios sistemas que precisam ser arquitetados.

Isso aumenta a importância do conhecimento arquitetural.

---

# 📌 Frase para memorizar

> **A melhor arquitetura não é a mais complexa nem a mais moderna. É aquela que resolve o problema corretamente dentro das restrições existentes e permite que o sistema evolua de forma sustentável.**
