# 🏗️ 01 — Introdução à Arquitetura de Software

## 📌 O que é Arquitetura de Software?

Arquitetura de Software é a organização estrutural de um sistema de software.

Ela define aspectos como:

* componentes;
* responsabilidades;
* relacionamentos;
* comunicação;
* armazenamento de dados;
* tecnologias;
* restrições;
* decisões técnicas;
* atributos de qualidade.

Podemos pensar na arquitetura como o **mapa estrutural de um sistema**.

---

## 🏠 Uma analogia

Podemos comparar software com a construção de uma casa.

Antes de construir:

```text
Projeto
   ↓
Estrutura
   ↓
Materiais
   ↓
Construção
```

No software:

```text
Requisitos
   ↓
Arquitetura
   ↓
Design
   ↓
Implementação
```

Uma arquitetura inadequada pode tornar o desenvolvimento, manutenção e evolução do sistema muito mais difíceis.

---

## 🎯 Por que Arquitetura de Software é importante?

A arquitetura influencia diretamente:

* manutenção;
* escalabilidade;
* segurança;
* desempenho;
* disponibilidade;
* confiabilidade;
* custos;
* capacidade de evolução.

Quanto maior o sistema, maior tende a ser o impacto das decisões arquiteturais.

---

## 🧩 Exemplo simples

```text
Usuário
   ↓
Frontend
   ↓
API
   ↓
Serviços
   ↓
Banco de Dados
```

Essa representação permite visualizar rapidamente como diferentes partes do sistema estão relacionadas.

---

## 💡 Ideia principal

> A arquitetura não existe para tornar o sistema mais complexo. Ela existe para organizar a complexidade necessária.
