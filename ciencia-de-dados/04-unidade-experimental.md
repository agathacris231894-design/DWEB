# 🔬 Unidade Experimental

A **unidade experimental** é o objeto de interesse sobre o qual os dados são coletados.

## Exemplos

| Unidade experimental | Exemplos de dados           |
| -------------------- | --------------------------- |
| Aluno                | Idade, notas, curso         |
| Cliente              | Idade, compras, localização |
| Paciente             | Idade, exames               |
| Produto              | Preço, vendas               |
| Veículo              | Velocidade, consumo         |

Em muitos conjuntos de dados, cada linha representa uma unidade experimental.

---

## 💡 Exemplo

Em uma tabela de alunos:

| Nome  | Idade | Curso | Nota |
| ----- | ----: | ----- | ---: |
| Ana   |    20 | ADS   |  8,5 |
| João  |    22 | ADS   |  7,0 |
| Maria |    21 | ADS   |  9,2 |

Cada aluno representa uma **unidade experimental**.
