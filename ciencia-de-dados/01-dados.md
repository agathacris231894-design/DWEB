# 📊 O que são Dados?

**Dados** são registros sobre pessoas, objetos, acontecimentos ou processos.

Eles podem ser coletados por:

* Pessoas
* Empresas
* Computadores
* Aplicativos
* Sensores
* Dispositivos IoT

## 📦 Formatos de dados

Os dados podem existir em diferentes formatos:

* Texto
* Números
* Imagens
* Vídeos
* Áudios
* Localização GPS
* Dados de sensores
* Redes sociais
* Bancos de dados
* Sistemas corporativos

---

## 🔄 Dados → Informação → Conhecimento

Uma maneira simples de representar esse processo:

```text
DADOS
  ↓
Organização
  ↓
INFORMAÇÃO
  ↓
Análise + Contexto
  ↓
CONHECIMENTO
  ↓
TOMADA DE DECISÃO
```

Dados isolados podem possuir pouco significado.

Quando são organizados, analisados e interpretados dentro de determinado contexto, podem gerar **informação** e **conhecimento** úteis para a tomada de decisões.

---

## 💡 Exemplo

Uma empresa pode possuir registros de compras:

| Cliente | Produto  | Horário |    Valor |
| ------- | -------- | ------: | -------: |
| 001     | Notebook |   14:30 | R$ 3.500 |
| 002     | Mouse    |   15:10 |    R$ 80 |
| 003     | Notebook |   16:20 | R$ 3.500 |

Ao analisar milhares de registros, a empresa pode identificar:

* Produtos mais vendidos;
* Horários de maior movimento;
* Perfil dos consumidores;
* Padrões de compra;
* Oportunidades de vendas.

Assim, os dados deixam de ser apenas registros e passam a gerar **informação e conhecimento**.

---

## 🎯 Resumo

```text
DADOS
↓
ORGANIZAÇÃO
↓
INFORMAÇÃO
↓
ANÁLISE + CONTEXTO
↓
CONHECIMENTO
↓

```

> **Dados são a matéria-prima. A análise transforma dados em conhecimento capaz de apoiar decisões.**
