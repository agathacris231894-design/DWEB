# 📊 O que são Dados?

**Dados** são registros sobre pessoas, objetos, acontecimentos ou processos.

Eles podem ser coletados por:

* Pessoas;
* Empresas;
* Computadores;
* Aplicativos;
* Sensores;
* Dispositivos IoT.

---

## 📦 Formatos de Dados

Os dados podem existir em diferentes formatos:

* Texto;
* Números;
* Imagens;
* Vídeos;
* Áudios;
* Localização GPS;
* Dados de sensores;
* Redes sociais;
* Bancos de dados;
* Sistemas corporativos.

---

## 🔄 Dados → Informação → Conhecimento

Uma maneira simples de representar esse processo:

```text
DADOS
  ↓
Organização
  ↓
INFORMAÇÃO
  ↓
Análise + Contexto
  ↓
CONHECIMENTO
  ↓
TOMADA DE DECISÃO
```

Dados isolados podem possuir pouco significado.

Quando são organizados, analisados e interpretados em determinado contexto, podem gerar **informações e conhecimentos úteis para a tomada de decisões**.
