# ⚖️ Small Data × Big Data

| Característica | Small Data                     | Big Data                                          |
| -------------- | ------------------------------ | ------------------------------------------------- |
| Fontes         | Tradicionais                   | Tradicionais + novas fontes                       |
| Volume         | Menor                          | Muito grande                                      |
| Velocidade     | Geralmente menor               | Pode exigir processamento rápido                  |
| Variedade      | Frequentemente estruturados    | Estruturados, semiestruturados e não estruturados |
| Veracidade     | Geralmente mais tratados       | Podem ser brutos e de qualidade variável          |
| Ferramentas    | Excel, SQL, bancos relacionais | NoSQL, Spark, Hadoop, Cloud                       |
| Análise        | BI e estatística               | Analytics, Machine Learning e IA                  |

---

## 📌 Observação

Não existe um limite universal de quantidade de dados que determine quando um conjunto passa a ser considerado Big Data.

O contexto, a velocidade, a variedade e as necessidades de processamento também são importantes.

---

## 🔎 Diferença simplificada

```text
SMALL DATA
↓
Conjuntos menores
↓
Ferramentas tradicionais
↓
Análise local ou convencional
```

```text
BIG DATA
↓
Grande escala
↓
Alta variedade e/ou velocidade
↓
Processamento distribuído
↓
Tecnologias especializadas
```
