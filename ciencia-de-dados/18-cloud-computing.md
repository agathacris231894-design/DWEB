# ☁️ Cloud Computing

**Computação em Nuvem (Cloud Computing)** permite utilizar recursos computacionais pela internet.

---

## 🖥️ Recursos

Entre os recursos disponíveis estão:

* Armazenamento;
* Processamento;
* Bancos de dados;
* Servidores;
* Machine Learning.

---

## ✅ Possíveis benefícios

* Escalabilidade;
* Flexibilidade;
* Disponibilidade;
* Acesso remoto;
* Redução da necessidade de infraestrutura própria.

---

## ☁️ Exemplos de provedores

* Amazon Web Services — AWS;
* Microsoft Azure;
* Google Cloud.

---

## 🔬 Cloud Computing e Ciência de Dados

A nuvem pode fornecer infraestrutura para:

```text
Coleta
  ↓
Armazenamento
  ↓
Processamento
  ↓
Análise
  ↓
Machine Learning
  ↓
Visualização
```

Isso permite que organizações utilizem recursos computacionais conforme suas necessidades.
