# 5️⃣ Os 5 Vs do Big Data

Os cinco Vs mais utilizados para caracterizar Big Data são:

1. **Volume**
2. **Velocidade**
3. **Variedade**
4. **Veracidade**
5. **Valor**

---

## 📦 1. Volume

Representa a quantidade de dados produzidos e armazenados.

Exemplos:

```text
Milhões de registros
Bilhões de transações
Terabytes
Petabytes
```

---

## ⚡ 2. Velocidade

Representa a velocidade com que os dados são:

* Gerados;
* Transmitidos;
* Processados;
* Analisados.

Exemplos:

* Pagamentos;
* GPS;
* Sensores;
* Redes sociais;
* Transações online.

---

## 🌎 3. Variedade

Representa a diversidade de formatos e fontes de dados.

Exemplos:

```text
Texto
Imagem
Vídeo
Áudio
Planilha
GPS
Sensor
Banco de dados
```

---

## ✔️ 4. Veracidade

Relaciona-se à qualidade, confiabilidade e incerteza dos dados.

É necessário identificar:

* Erros;
* Duplicações;
* Inconsistências;
* Dados incompletos;
* Informações incorretas.

---

## 💎 5. Valor

Representa a capacidade de transformar dados em conhecimento e benefícios.

```text
DADOS
  ↓
ANÁLISE
  ↓
INSIGHT
  ↓
AÇÃO
  ↓
VALOR
```

Possuir muitos dados não significa, por si só, que uma organização esteja obtendo valor deles.

---

## 📌 Resumo

| V          | Significado                |
| ---------- | -------------------------- |
| Volume     | Quantidade                 |
| Velocidade | Rapidez                    |
| Variedade  | Diversidade                |
| Veracidade | Qualidade e confiabilidade |
| Valor      | Benefício gerado           |
