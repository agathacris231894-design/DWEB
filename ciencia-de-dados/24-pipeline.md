# 🔄 Pipeline de Ciência de Dados

Um projeto de Ciência de Dados pode seguir um fluxo semelhante a:

```text
              ┌──────────────┐
              │    COLETA    │
              └──────┬───────┘
                     ↓
              ┌──────────────┐
              │ ORGANIZAÇÃO  │
              └──────┬───────┘
                     ↓
              ┌──────────────┐
              │   LIMPEZA    │
              └──────┬───────┘
                     ↓
              ┌──────────────┐
              │ EXPLORAÇÃO   │
              └──────┬───────┘
                     ↓
              ┌──────────────┐
              │  MODELAGEM   │
              └──────┬───────┘
                     ↓
              ┌──────────────┐
              │  AVALIAÇÃO   │
              └──────┬───────┘
                     ↓
              ┌──────────────┐
              │ VISUALIZAÇÃO │
              └──────┬───────┘
                     ↓
              ┌──────────────┐
              │ COMUNICAÇÃO  │
              └──────┬───────┘
                     ↓
              ┌──────────────┐
              │   DECISÃO    │
              └──────────────┘
```

---

## 1. 📥 Coleta

Obtenção dos dados a partir de fontes como:

* Bancos de dados;
* APIs;
* Arquivos;
* Sensores;
* Sistemas;
* Aplicativos.

---

## 2. 🗂️ Organização

Estruturação dos dados para facilitar seu processamento e análise.

---

## 3. 🧹 Limpeza

Identificação e tratamento de:

* Dados ausentes;
* Duplicações;
* Erros;
* Inconsistências;
* Outliers;
* Ruídos.

---

## 4. 🔎 Exploração

Busca por:

* Padrões;
* Tendências;
* Relações;
* Distribuições;
* Anomalias.

---

## 5. 🤖 Modelagem

Aplicação de métodos estatísticos ou modelos de Machine Learning quando necessário.

---

## 6. ✅ Avaliação

Verificação da qualidade dos resultados obtidos.

---

## 7. 📊 Visualização

Transformação dos resultados em representações que facilitem sua interpretação.

---

## 8. 📖 Comunicação

Apresentação dos resultados para diferentes públicos.

Pode envolver:

* Relatórios;
* Dashboards;
* Apresentações;
* Data Storytelling.

---

## 9. 🎯 Decisão

Utilização dos resultados para apoiar ações e decisões.

---

> **Importante:** esse processo não é necessariamente linear. Em projetos reais, é comum retornar a etapas anteriores quando novos problemas ou informações são identificados.
