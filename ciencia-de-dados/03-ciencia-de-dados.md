# 🔬 Ciência de Dados

**Ciência de Dados (Data Science)** é uma área interdisciplinar que utiliza diferentes conhecimentos para coletar, organizar, processar, analisar e interpretar dados.

---

## 🧩 Áreas relacionadas

Entre as áreas relacionadas estão:

* Matemática;
* Estatística;
* Programação;
* Banco de Dados;
* Inteligência Artificial;
* Machine Learning;
* Visualização de Dados;
* Conhecimento de negócios.

---

## 🎯 Objetivo

O objetivo da Ciência de Dados é transformar dados em conhecimento capaz de gerar **insights** e apoiar decisões.

```text
DADOS
  ↓
PROCESSAMENTO
  ↓
ANÁLISE
  ↓
MODELAGEM
  ↓
INSIGHT
  ↓
DECISÃO
  ↓
VALOR
```

---

## 🧠 Conceito

A Ciência de Dados não está limitada à programação.

Ela combina conhecimentos técnicos e de negócio para responder perguntas, encontrar padrões, realizar previsões e apoiar processos de decisão.
