Exemplos:

* Apache Spark;

---

## 🐘 Apache Hadoop

Ecossistema utilizado para armazenamento e processamento distribuído de grandes conjuntos de dados.

---

## ⚡ Apache Spark

Engine de processamento distribuído utilizada para processamento de dados em larga escala.

---

## 🗄️ NoSQL

Categoria de bancos de dados que utiliza modelos diferentes do modelo relacional tradicional.

Exemplos:

* MongoDB;
* Cassandra;
* Redis.

---

## ☁️ Data Lakes

Ambientes utilizados para armazenar grandes quantidades de dados em diferentes formatos, incluindo dados estruturados, semiestruturados e não estruturados.
