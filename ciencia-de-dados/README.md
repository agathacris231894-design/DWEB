## 🧭 Visão geral

O estudo de Ciência de Dados envolve diferentes etapas e conhecimentos:

```text
                         DADOS
                           ↓
                    ORGANIZAÇÃO
                           ↓
                       LIMPEZA
                           ↓
                      EXPLORAÇÃO
                           ↓
                        ANÁLISE
                           ↓
                       MODELAGEM
                           ↓
                    VISUALIZAÇÃO
                           ↓
                      INSIGHT
                           ↓
                       DECISÃO
                           ↓
                         VALOR
```

A área combina conhecimentos de:

* Programação
* Estatística
* Matemática
* Banco de Dados
* Machine Learning
* Inteligência Artificial
* Visualização de Dados
* Conhecimento de negócio
