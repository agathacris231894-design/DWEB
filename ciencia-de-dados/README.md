# 📌 O que são Dados?

Dados são registros sobre pessoas, objetos, acontecimentos ou processos.

Podem ser encontrados em diferentes formatos:

- Texto
- Números
- Imagens
- Vídeos
- Áudios
- Localização GPS
- Sensores
- Redes sociais
- Bancos de dados
- Sistemas corporativos

Os dados podem ser processados e analisados para gerar **informações, conhecimento e insights**.
