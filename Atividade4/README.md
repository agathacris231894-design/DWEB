# 🧬 GENOMA — A história da vida escrita no DNA

> Projeto acadêmico desenvolvido para apresentar, de forma visual e interativa, conceitos relacionados à genética, hereditariedade, mutações, evolução, filogenia, genômica e filogenômica.

---

## 📖 Sobre o projeto

O **GENOMA** é um site educacional que apresenta uma jornada pelo conhecimento sobre o DNA e sua importância para compreender a diversidade e a história evolutiva da vida.

O projeto foi desenvolvido com uma abordagem visual e progressiva. Os conteúdos são organizados em diferentes etapas, permitindo que o usuário acompanhe a relação entre os conceitos, desde a genética básica até a análise de genomas e a reconstrução de relações evolutivas.

A proposta é mostrar que o DNA não representa apenas a informação genética de um organismo, mas também pode fornecer evidências sobre sua história e suas relações evolutivas.

---

## 🎯 Objetivos

* Apresentar conceitos fundamentais de genética e biologia evolutiva;
* Explicar a relação entre DNA, genes e genomas;
* Demonstrar como ocorre a transmissão e a variação genética;
* Apresentar mecanismos relacionados à evolução;
* Introduzir o conceito de filogenia;
* Demonstrar a importância da genômica;
* Apresentar a filogenômica como ferramenta para estudar a história evolutiva;
* Relacionar Biologia e Computação por meio da análise de dados genômicos;
* Desenvolver uma experiência de navegação simples e organizada.

## 💻 Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais para desenvolvimento web:

* **HTML5** — estrutura e organização das páginas;
* **CSS3** — estilização, layout e responsividade;
* **CSS Grid** — construção dos layouts das páginas;
* **Git** — controle de versão;
* **GitHub** — armazenamento e compartilhamento do projeto.

O site foi desenvolvido **sem JavaScript**, utilizando recursos nativos de HTML e CSS para a navegação e interação do menu lateral.

---

## 🎨 Características do projeto

### Menu lateral

O site possui um menu lateral que permite navegar entre os diferentes grids.

O menu utiliza:

* `checkbox`;
* `label`;
* CSS;
* posicionamento `fixed`;
* transições em CSS.

Dessa forma, não foi necessário utilizar JavaScript para controlar a abertura e o fechamento do menu.

### Layout com CSS Grid

O projeto utiliza **CSS Grid como principal sistema de layout**.

Os grids são utilizados para organizar:

* menus;
* cards;
* seções;
* etapas da jornada;
* referências;
* elementos da página inicial.

### Responsividade

O CSS possui regras `@media` para adaptar o conteúdo a diferentes tamanhos de tela.

Em telas menores, os elementos são reorganizados para facilitar a leitura e a navegação.
