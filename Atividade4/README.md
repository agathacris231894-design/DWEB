# 🌱 Portal da Biologia

Um portal de notícias fictício desenvolvido para praticar **HTML5, CSS3, CSS Grid e Flexbox**, utilizando como tema principal as Ciências Biológicas.

O projeto apresenta uma página de notícias organizada em diferentes categorias da Biologia, com destaque para **Genética, Botânica, Zoologia, Conservação e Eventos**.

## 🧬 Sobre o projeto

O **Portal da Biologia** foi desenvolvido como um exercício de desenvolvimento web com o objetivo de aplicar conceitos de estruturação de páginas e criação de layouts utilizando **CSS Grid e Flexbox**.

A página simula um portal de notícias científicas, apresentando:

* Notícia principal sobre a importância da diversidade vegetal;
* Notícias sobre genética;
* Conteúdos relacionados à zoologia;
* Destaques sobre biodiversidade e conservação;
* Últimas notícias;
* Lista de notícias mais lidas;
* Menu de navegação por categorias;
* Layout responsivo para diferentes tamanhos de tela.

## 🌿 Categorias

O portal possui as seguintes categorias:

* 🏠 **Início**
* 🧬 **Genética**
* 🌱 **Botânica**
* 🐾 **Zoologia**
* 🌎 **Conservação**
* 🔬 **Eventos**

## 💻 Tecnologias utilizadas

* **HTML5** — estrutura e organização do conteúdo;
* **CSS3** — estilização da página;
* **CSS Grid** — criação do layout principal;
* **Flexbox** — organização dos elementos dentro das seções;
* **Media Queries** — adaptação do site para diferentes tamanhos de tela.

## 📐 Layout

O layout principal foi desenvolvido utilizando **CSS Grid**, com diferentes áreas destinadas às notícias.

A estrutura utiliza `grid-template-areas` para organizar as principais seções:

* **A** — notícia principal;
* **B** — notícia de Genética;
* **C** — notícia de Zoologia;
* **D** — destaques;
* **E** — últimas notícias;
* **F** — notícias mais lidas.

O **Flexbox** é utilizado para organizar elementos como o cabeçalho, menu, listas de notícias e conteúdos internos dos cards.

## 📱 Responsividade

O projeto possui regras de responsividade utilizando `@media`, permitindo que o layout seja adaptado para:

* 💻 Computadores;
* 📱 Celulares;
* 📲 Tablets.

Em telas menores, as áreas do Grid são reorganizadas para que o conteúdo seja apresentado em uma única coluna.
